🔍 Webflow Debug Console

A sophisticated debugging tool for Webflow websites

Launch Debug Console

Or press Cmd/Ctrl + Shift + D

How to Use

  1. Click the "Launch Debug Console" button above
  2. Wait for the glassmorphic console to appear
  3. Explore the different tabs to see various audits
  4. Click on issues to highlight elements on the page
  5. Export a comprehensive HTML report

Features Overview

⚡ Performance

Track Core Web Vitals, page load time, and resource breakdown

🐛 Error Tracking

Real-time JavaScript error capture with stack traces

♿ Accessibility

Detect missing alt tags, labels, and ARIA attributes

🔎 SEO

Audit meta tags, headings, and image optimization

🌐 Network

Monitor HTTP requests, failed loads, and slow assets

🎨 CSS/Layout

Find overflow issues, z-index conflicts, and more

Installation Methods

1. Bookmarklet

Create a bookmark with this code:

javascript:(function(){...bookmarklet code...})();

2. Browser Console

Copy and paste webflow-debug-console.js into your browser console

3. Script Tag

Add to your Webflow custom code:

<script src="https://your-cdn.com/webflow-debug-console.js"></script>
